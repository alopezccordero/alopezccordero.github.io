Reinforcement Learning · Character Control

Adversarial Motion Priors for Humanoid Locomotion

Extended Stable-Baselines3 PPO with a custom Adversarial Motion Priors implementation, including a discriminator neural network, AMP reward integration, and a motion-retargeting pipeline. I processed AMASS motion-capture data and retargeted it to the MuJoCo humanoid skeleton to create expert demonstrations, then trained the policy for more than 50 million environment interactions on GPU clusters.

  • Eval (10 episodes, deterministic): 971.74 ± 13.51 episode reward.

Deep Learning · Computer vision AI

YOLO-GunRecognizer

A single-class YOLO model (class: "gun") designed for live-monitoring and real-surveillance frames. Trained on YOLO26s neural network architecture by peforming downsampling techniques, hard-negative integration and inspecting data-leakages. The model was improved by 3.8x and evaluated against UGR and SOHA benchmark.

  • Eval UGR benchmark: P 0.922 R 0.787 mAP50 0.850 mAP50-95 0.637 | R@0.2 0.824 P@0.865 real-CCTV-recall improved from 0.149 (baseline) to 0.568
  • Eval SOHA: P 0.710 R 0.800 mAP50 0.787 mAP50-95 0.654 | R@0.2 0.952 P@0.2 0.400

Machine Learning · Model Selection

ApisTox: Honeybee Toxicity Classification

Developed a machine-learning pipeline to classify pesticides as toxic or non-toxic to honeybees. Compared K-Nearest Neighbors, Logistic Regression, and Neural Networks, tested different combinations of dataset columns to identify the most informative feature set, and evaluated multiple hyperparameter combinations to select the strongest model.

  • Compared KNN, Logistic Regression, and Neural Network classifiers.
  • Searched combinations of input columns to find the best-performing feature subset.
  • Tuned model hyperparameters and compared results using classification metrics.
  • Best metric: Neural Network - accuracy: 0.8922 - std: 0.0280
